## Домашняя работа №3.
В файле ДЗ3 представлена игра-лабиринт. Программа демонстрирует практическое применение встроенных методов списков, а также базовых конструкций языка: циклов, условных операторов и функций. Игрок перемещается по карте 5×5, собирает предметы, сражается с монстрами и ищет выход из лабиринта.
### Состав работы:
#### game.py - Игра-лабиринт.
Программа реализует интерактивную игру, в которой игрок управляет персонажем с помощью клавиш w/a/s/d. В коде последовательно применяются все требуемые методы списков:
- **append()** - добавление предметов в инвентарь (ключ, меч) при подборе в комнатах.
- **remove()** - удаление использованного ключа из инвентаря после открытия сундука.
- **pop()** - удаление последнего предмета из инвентаря по команде игрока (q).
- **sort()** и **reverse()** - сортировка и разворот инвентаря по команде игрока (i).
- **index()** и **in** - поиск предмета в инвентаре и проверка его наличия.
- **slice ([:])** - копирование карты лабиринта через срезы, чтобы изменения в игре не влияли на исходный шаблон.
- **list comprehension** - формирование кода двери и разбор введённого игроком кода.

## Домашняя работа №4.
В файле ДЗ4 представлена практическая работа по анализу и обработке данных с использованием библиотек Pandas и NumPy. Работа выполнена на основе датасета пассажиров «Титаник» (Titanic dataset) и демонстрирует полный цикл первичного анализа данных (EDA), обработку пропусков, фильтрацию и группировку.

### Состав работы:
#### titanic.ipynb - Основной скрипт (Jupyter Notebook).
Программа реализует последовательный анализ данных, от загрузки до сохранения результатов. В коде применяются следующие методы и конструкции:
- **head() / tail() / shape / dtypes** - первичный анализ структуры таблицы (первые/последние строки, размер, типы данных).
- **isnull() / sum() / idxmax()** - поиск и анализ количества пропущенных значений по каждому столбцу.
- **fillna()** - заполнение пропусков в столбце Age медианой.
- **dropna() / drop()** - удаление строк с отсутствующим портом Embarked и удаление столбца Cabin (так как доля пропусков в нем превышает 50%).
- **to_numpy() и методы NumPy (mean, min, max, std)** - перевод столбцов в массивы и расчет статистических показателей (процент выживших, средний возраст, стандартное отклонение).
- **Булева индексация (&, |)** - фильтрация данных по сложным условиям
- **groupby() и agg()** - группировка данных по классам, полу и портам посадки с вычислением средних значений и процентов.
- **to_csv()** - сохранение очищенного датасета и результатов группировки в новые файлы.

#### titanic_processed.csv - Очищенный датасет.
Итоговая таблица (889 строк, 11 столбцов), полученная после заполнения пропусков в возрасте, удаления строк без порта отправления и исключения столбца Cabin.

#### titanic_statistics.csv - Результаты группировки.
Сводная таблица со статистикой по классам и полу (количество пассажиров, средний возраст, доля выживших и средняя стоимость билета).
