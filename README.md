## Домашняя работа №1.
В файле ДЗ1 представлены файлы с кодами, которые демонстрируют постепенный переход от базового кода к объектно-ориентированному программированию (ООП). Также реализован конвертер температур с использованием класса.

### Cостав работы:
#### 1_calculator.py - Базовый калькулятор.
Код выполняется последовательно, без использования функций (def) и классов. 
#### 2_calculator_def.py - Калькулятор с функциями.
Код разбит на четыре отдельные функции: plus, minus, umnojenie, delenie. 
#### 3_calculator_while.py - Калькулятор с функциями и циклом.
Тот же набор функций, что и в предыдущем файле, но с бесконечным циклом 'while True'. Программу не нужно перезапускать для каждого нового вычисления.
#### 4_calculator_class.py - Калькулятор на классах.
Создан класс 'calculator', который хранит числа a и b внутри объекта и предоставляет методы для выполнения арифметических операций.
#### 5_temperature_class.py - Конвертер температур на классах.
Класс 'temperature_converter' переводит температуру из Цельсия в Кельвины и обратно. 

## Домашняя работа №2. 
В файле ДЗ2 находится работа, которая представляет собой интерактивный тренажёр для изучения и практического применения встроенных методов строк в Python. Программа состоит из 5 уровней, каждый из которых демонстрирует определённую группу методов.
### Структура уровней:
#### Уровень 1: 
Изучение методов upper(), lower(), capitalize().
#### Уровень 2:
Работа с методами find(), replace(), count().
#### Уровень 3: 
Использование методов split() и join().
#### Уровень 4:
Применение методов isdigit(), isalpha(), strip().
#### Уровень 5: 
На примере строки демонстрируется последовательное применение всех изученных методов для очистки текста от лишних символов, исправления пробелов и приведения слов к формату написание с большой буквы.
